# Recording script for Experiment 3 (speech-to-text)

Read each numbered line aloud as if giving a command to an assistant. Do not read the notes in brackets.

## How to record
- Quiet room, the microphone you will actually demo with, your normal voice and pace.
- One recording per section (V1, V2, ...). Start with about 1 second of silence, read the lines in order with a **2 second pause** between them, and end with about 1 second of silence.
- If you stumble, pause 3 seconds and read that line again, then tell me which line it was. Or re-record the whole file.
- Save as WAV if you can (mono, 16 kHz or higher), named `V1.wav`, `V2.wav`, and so on, in `03_Speech_To_Text/recordings/`. Other formats are fine if I can read them.
- Say numbers and names the way you naturally would.

## V0 - Silence (10 seconds, do not speak)
Just record 10 seconds of the quiet room. This checks that no engine invents words from silence.
